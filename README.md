# Coral Quest

Game edukasi 3D interaktif berbasis web tentang terumbu karang untuk masyarakat Kepri (Prototipe Esai IMPACT 2026).

**Tim Coral Quest:** 
- Aria Dimas Mastur (Ketua)
- Yohani Natalia S
- Grayesi Silitonga

## 🎮 Fitur Utama
* **4 Misi Utama:** (1) Peran Makhluk Karang, (2) Jaring Makanan, (3) Cek Kesehatan Karang, dan (4) Simulasi Restorasi. Diakhiri dengan rapor nilai dan ikrar aksi.
* **Mode Bermain:** Mode Cepat (singkat) dan Mode Kelas (materi lebih lengkap + kuis).
* **Dukungan Bahasa:** Inggris (default) dan Indonesia. Teks dapat diubah di `js/i18n.js`.
* **Audio Cerdas:** Musik & efek suara dihasilkan langsung oleh kode (mendukung offline). Bisa diganti dengan file mp3 sendiri di folder `audio/`.

## 💻 Cara Menjalankan
* **Komputer (Lokal):** Game tidak bisa dibuka dengan klik dua kali pada `index.html`. Gunakan server lokal (misalnya `python -m http.server 8000` di terminal atau ekstensi *Live Server* di VS Code), lalu buka di localhost.
* **Online & HP (GitHub Pages):** Unggah folder ke repositori GitHub dan aktifkan **GitHub Pages**. Game dapat diakses melalui tautan, ditambahkan ke layar utama HP, dan **bisa dimainkan secara offline** (PWA).
